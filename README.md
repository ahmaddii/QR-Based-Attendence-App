# QR Code Attendance System

> A mobile attendance management system that replaces manual roll calls with dynamic, time-expiring QR code check-ins.

The QR Code Attendance System is a Flutter-based mobile application designed to simplify university attendance management.

The system provides separate experiences for **Teachers** and **Students**, allowing instructors to create attendance sessions and broadcast dynamically generated QR codes while students scan them to record their attendance.

By combining **dynamic QR codes, geolocation, device binding, and offline synchronization**, the system is designed to make attendance faster while reducing opportunities for unauthorized check-ins.

---

## 🚀 Overview

Traditional university attendance often relies on manual paper-based roll calls or static attendance methods.

This system digitizes the process:

```text
Teacher
   ↓
Create Attendance Session
   ↓
Generate Dynamic QR Code
   ↓
Student Scans QR
   ↓
Validate Attendance
   ↓
Record Check-in
   ↓
Attendance Report
